# cspell-dictionary

This library was generated with [Nx](https://nx.dev).

## Building

Run `nx build cspell-dictionary` to build the library.

## Running unit tests

Run `nx test cspell-dictionary` to execute the unit tests via [Vitest](https://vitest.dev/).
